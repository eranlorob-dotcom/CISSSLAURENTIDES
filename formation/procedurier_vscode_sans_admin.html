Installer VS Code sans droits d'administrateur

Utiliser la version « User Installer » de Visual Studio Code, conçue pour s'installer dans le profil de l'utilisateur — sans élévation de privilèges Windows.

CISSS des Laurentides — Direction de santé publique
Contexte : dans un environnement institutionnel (poste CISSS), les politiques de sécurité locales peuvent tout de même bloquer certaines installations même sans droits admin. Si le blocage persiste, contacter le soutien informatique pour une installation via le catalogue logiciel approuvé.
Téléchargement
1

Accéder à la page de téléchargement officielle

Ouvrir un navigateur et aller à :

https://code.visualstudio.com/download
2

Choisir la version « User Installer »

Sous Windows, ne pas prendre le bouton principal « Download for Windows » (c'est l'installateur système). Cliquer plutôt sur la flèche à côté, ou chercher le lien direct :

ArchitectureType de fichier
64 bits (la grande majorité des postes)VSCodeUserSetup-x64-{version}.exe
ARM64VSCodeUserSetup-arm64-{version}.exe

Le mot-clé UserSetup confirme qu'il s'agit bien de la version sans droits administrateur.

Installation
3

Lancer l'installateur téléchargé

Double-cliquer sur le fichier .exe téléchargé (généralement dans le dossier Téléchargements). Aucune demande d'élévation (UAC) ne devrait apparaître, puisque l'installation se fait entièrement dans le profil utilisateur.

4

Suivre l'assistant d'installation

Accepter la licence, garder l'emplacement par défaut proposé (dans %LOCALAPPDATA%\Programs\Microsoft VS Code), et cocher au besoin :

  • Ajouter au PATH
  • Ajouter une action « Ouvrir avec Code » au menu contextuel
5

Terminer et lancer VS Code

Cliquer sur Terminer. VS Code s'installe uniquement pour le compte utilisateur courant (pas pour tous les utilisateurs de la machine) et se lance automatiquement.

Solutions de rechange
6

Version portable (ZIP), si l'exécutable est bloqué

Si les politiques du poste empêchent même l'exécution d'un .exe téléchargé, une alternative est la version ZIP portable :

https://code.visualstudio.com/Download → section « ZIP »

Télécharger l'archive, l'extraire dans un dossier personnel (par exemple Documents\VSCode), puis lancer Code.exe directement — aucune installation requise.

Astuce : la version User Installer et la version portable fonctionnent identiquement pour le développement web (Leaflet, GitHub Pages) et acceptent toutes les mêmes extensions, y compris Live Server.
