Qu'est-ce que l'API Overpass ?

Overpass est une API en lecture seule qui interroge la base de données d'OpenStreetMap. On lui envoie une requête écrite en Overpass QL et elle renvoie les objets correspondants (souvent en JSON).

Trois types d'objets OSM

  • node — un point (ex. une pharmacie, un arrêt de bus)
  • way — une ligne ou un polygone (ex. le contour d'un hôpital, une rue)
  • relation — un groupe d'objets (ex. un parcours d'autobus)

Chaque objet porte des étiquettes (tags) clé=valeur, comme amenity=pharmacy. Le raccourci nwr interroge les trois types à la fois.

Anatomie de la requête

[out:json][timeout:25];
(
  nwr[amenity=pharmacy](45.7,-74.1,45.9,-73.9);
);
out center;

[out:json] = format de sortie · les 4 nombres = la zone (sud,ouest,nord,est) · out center; donne un point central aux polygones, pratique pour les afficher.

L'appel en JavaScript (ce que fait cet outil)

fetch('https://overpass-api.de/api/interpreter', {
  method: 'POST',
  body: 'data=' + encodeURIComponent(requete)

Bon voisinage

Le serveur public est gratuit mais partagé : limitez la zone (zoom suffisant), évitez les requêtes répétées inutiles, et créditez toujours OpenStreetMap. Pour un usage intensif, on héberge sa propre instance.
