Installer Live Server dans VS Code

Extension de prévisualisation locale avec rechargement automatique — utile pour tester les outils Leaflet et pages de formation avant leur publication sur GitHub Pages.

CISSS des Laurentides — Direction de santé publique
Installation
1

Ouvrir le panneau des extensions

Dans VS Code, cliquer sur l'icône des extensions dans la barre latérale gauche (carrés empilés), ou utiliser le raccourci :

Ctrl + Shift + X (Windows)  ·  Cmd + Shift + X (Mac)

2

Rechercher l'extension

Taper Live Server dans la barre de recherche.

Repérer l'extension publiée par Ritwick Dey (icône orange avec un éclair).

3

Installer

Cliquer sur le bouton Install. L'installation prend quelques secondes ; aucun redémarrage n'est généralement requis.

Utilisation
4

Ouvrir un fichier HTML

Ouvrir le fichier .html à prévisualiser (par exemple un outil cartographique du projet C.A.R.T.O.S.).

5

Lancer le serveur

Clic droit dans l'éditeur → « Open with Live Server »

Ou cliquer sur « Go Live » en bas à droite de la barre d'état.

http://127.0.0.1:5500/nom-du-fichier.html
6

Arrêter le serveur

Cliquer sur « Port: 5500 » en bas à droite → « Stop Server ».

Astuce formation : chaque sauvegarde du fichier HTML rafraîchit automatiquement la page dans le navigateur — pratique pour démontrer des modifications en direct aux participants sans recharger manuellement.
