Cartographie Interactive et Géoweb

Formation 4h30 pour professionnels de santé publique

QGIS + Leaflet.js + IA (Claude) + GitHub Pages

Information générale

Durée 4h30 (avec pause de 20 minutes)
Public cible Professionnels de santé publique, planificateurs, décideurs
Prérequis Connaissances SIG de base ou expérience avec des données spatiales
Logiciels QGIS + VS Code + Git + navigateur web + compte GitHub (gratuit)

Description

Cette formation intensive combine QGIS pour préparer les données spatiales, Leaflet pour créer des cartes web interactives, Claude (IA) pour accélérer l'apprentissage et le debugging, et GitHub Pages pour publier en ligne. Les participants apprendront à transformer des données de santé publique en représentations cartographiques interactives partagées sur le web.

Objectifs d'apprentissage

  • Comprendre la chaîne de production QGIS → GeoJSON → Leaflet → GitHub

  • Préparer et visualiser des données spatiales en santé publique avec QGIS

  • Créer une carte web interactive avec Leaflet.js

  • Utiliser Claude (IA) pour déboguer et apprendre les concepts techniques

  • Publier et tester votre carte en ligne via GitHub Pages

  • Évaluer les avantages et limites de ces outils pour vos contextes de travail

Thématiques clés abordées

  • Architecture client-serveur et protocoles du Web (GeoJSON, API REST)

  • Préparation de données spatiales en QGIS (import, nettoyage, export GeoJSON)

  • Programmation d'interfaces interactives avec Leaflet.js (JavaScript simple)

  • Utiliser Claude (IA) pour l'apprentissage : poser des questions, déboguer du code, générer des extraits

  • Publier sur GitHub Pages : cloner, modifier, commit/push, tester en ligne

  • Cas d'application en santé publique : accessibilité, santé mentale, équité géospatiale

  • Enjeux éthiques : représentation spatiale, vie privée, interprétation des données

Rôle de Claude (IA) dans la formation

Apprentissage accompagné

Claude aide à comprendre les concepts : expliquez un terme QGIS ou du JavaScript et Claude propose une explication claire avec des exemples.

Déboggage et correction

Vous avez une erreur en JavaScript ? Collez le code et la trace d'erreur à Claude, qui explique le problème et propose une correction.

Génération de code

Claude génère des portions de code Leaflet (popups, légendre, styles) à partir de descriptions en français.

Exploration créative

Vous avez une idée pour votre carte ? Claude peut vous aider à la structurer, proposer des outils, ou générer un prototype.

Publication sur GitHub Pages

À la fin de la formation, chaque participant publiera sa carte en ligne via GitHub Pages (service gratuit). Les étapes incluent :

  1. Créer un compte GitHub (5 minutes)

  2. Cloner ou créer un dépôt (repository)

  3. Ajouter votre fichier HTML avec la carte Leaflet

  4. Committer et pusher les changements (git commands)

  5. Activer GitHub Pages (une case à cocher)

  6. Accéder à votre carte en ligne via une URL unique (ex: votreusername.github.io/votre-carto)

  7. Tester et partager la carte avec vos collègues

Exemples de cas d'usage en santé publique

  • Accessibilité aux services de santé par secteur (carte des délais, disparités géographiques)

  • Distribution de problèmes de santé mentale par quartier avec tendances

  • Couverture vaccinale par région et comparaisons temporelles

  • Cartographie des déterminants sociaux de la santé (pauvreté, scolarité, emploi)

  • Environnement et santé : pollution, verdure, accès à espaces verts de proximité

Critères de succès

À la fin de cette formation, vous serez capable de :

  1. Importer un fichier de données spatiales dans QGIS et créer une visualisation thématique

  2. Exporter des données en format GeoJSON

  3. Créer une page HTML avec une carte Leaflet interactive et stylisée

  4. Ajouter de l'interactivité (popups, info-bulles)

  5. Utiliser Claude pour déboguer du code et comprendre les concepts

  6. Publier et tester votre carte en ligne via GitHub Pages

  7. Identifier les forces et faiblesses de ce workflow pour vos projets futurs
