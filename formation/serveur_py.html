Lancer un serveur HTTP local avec Python

Pour tester un outil cartographique HTML (Leaflet, QGIS2Web, etc.) dans un navigateur avant sa mise en ligne.

py -m http.server 8080
Prérequis — Python doit être installé (le lanceur py est inclus avec l'installateur officiel sur Windows). Pour vérifier : ouvrir un terminal et taper py --version.

Étapes

  1. Ouvrir un terminal dans le bon dossier

    Dans l'explorateur de fichiers, se placer dans le dossier contenant les fichiers HTML à servir, cliquer dans la barre d'adresse, taper cmd puis Entrée.

    Ou naviguer manuellement depuis un terminal déjà ouvert :

    cd chemin\vers\le\dossier

  2. Lancer le serveur

    Taper la commande suivante puis Entrée :

    py -m http.server 8080

    Le terminal confirme le démarrage avec un message du type « Serving HTTP on … port 8080 ».

  3. Ouvrir le site dans le navigateur

    Se rendre à l'une de ces adresses :

    http://localhost:8080
    http://127.0.0.1:8080

    Cliquer ensuite sur le fichier .html voulu dans la liste affichée.

  4. Arrêter le serveur

    Retourner dans le terminal et appuyer sur Ctrl + C. Fermer la fenêtre du terminal arrête aussi le serveur.

Dépannage

SituationSolution
Port 8080 déjà utiliséChoisir un autre port : py -m http.server 8081
py non reconnuEssayer python -m http.server 8080 ou python3 -m http.server 8080
Erreur de connexion dans le navigateurVérifier que le terminal est resté ouvert — le serveur s'arrête à sa fermeture
Servir un dossier précis sans s'y déplacerpy -m http.server 8080 --directory "chemin\vers\dossier"
Accès depuis un autre appareil du même réseauRemplacer localhost par l'adresse IP locale (ipconfig sous Windows)

Cas d'usage typique

Utile pour tester localement un outil cartographique HTML autonome (Leaflet, etc.) avant sa mise en ligne sur GitHub Pages — en particulier lorsque le fichier fait des appels à des données externes (GeoJSON, tuiles) qui nécessitent un vrai serveur plutôt qu'une simple ouverture via file://.
